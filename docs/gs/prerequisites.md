# Prerequisites

Install the tools you need for the example project you plan to build. The
projects in this repository target Java 25 and use the Gradle wrapper.

Before you begin, install:

- JDK 25.
- Git.
- Docker, if you run an example with Testcontainers or Micronaut Test Resources.
- An editor or IDE, such as Visual Studio Code or IntelliJ IDEA.

You do not need to install Gradle separately. Each Gradle example includes a
wrapper. Database-backed tests need Docker; starting an application against a
local database also requires that database to be available.
