# Preface

This guide helps Java developers familiar with Spring understand Micronaut and build small applications with its dependency injection, HTTP, data, and testing APIs. The examples also include Kotlin, Kotlin Coroutines, and Groovy.

The examples use Java 25. Some projects use other JVM languages and may have language-specific prerequisites.

## Get the examples

The [micronaut-sandbox repository](https://github.com/hantsy/micronaut-sandbox)
contains the example projects. Clone it with Git:

```bash
git clone https://github.com/hantsy/micronaut-sandbox.git
```

See [Getting started](./gs/index.md) for the example project index and
[Prerequisites](./gs/prerequisites.md) before you build or run a sample.

## Contribute
